# 佳安工地导航 · JIA AN Worksite Navigation

**https://jiaan-construction.github.io/site-nav/**

手机打开，按区域找工地，点「导航」直接唤起地图，点「坐标」复制经纬度转发。20 处在建工地。

## 说明

- 坐标是**导航参考，不代表塔吊机位**。标「位置已核实」的是确认过的门口/地址点；标「区域级近似」的按现场为准。
- 大士几个标段（C2A / C3C / C4A / C6A）共用一个坐标，进场后按标段指示牌走。
- 内容来源：情报库 `04-项目工地/` 的工地卡。工地有增减时改本仓库的 `index.html` 里 `SITES` 那一段。

## 这个仓库不放什么

工地名称、总包、大致地址属于对外可见范围（公司业绩表里本来就有）。**但下面这些一律不进**：

- 位于受限设施内的项目
- 司机姓名、电话、准证信息
- 费率、合同额

> 单文件，无依赖，无构建步骤。
