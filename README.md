# 佳安工地导航 · JIA AN Worksite Navigation

**https://jiaan-construction.github.io/site-nav/**

手机打开，按区域找工地，点「导航」直接唤起地图，点「坐标」复制经纬度转发。地图上可以直接看位置。20 处在建工地。

## 说明

- 坐标是**导航参考，不代表塔吊机位**。标「位置已核实」的是确认过的地址点；标「区域级近似」的按现场为准。
- 大士几个标段（C2A / C3C / C4A / C6A）共用一个坐标，进场后按标段指示牌走。

## 这个页面是生成的，不要手改

```
04-项目工地/工地：*.md          ← 位置事实源，人只改这里
        │  sync_from_vault.py --write
        ▼
   output/sites.json            ← 机器可读数据（生成物）
        │  build_nav.py --target public
        ▼
      index.html                ← 本仓库这个文件
```

**改一个工地：改工地卡 → 跑两个脚本 → 推这里。** 直接改 `index.html` 会在下一次生成时被覆盖。
脚本在情报库 `jiaan-map-dispatch/`。

## 公开版的四道闸门（写在构建脚本里，不靠记性）

1. 清空所有内部备注
2. 拒绝读取司机位置文件，存在也不读
3. 产物回扫内部字眼，命中就删产物并退出
4. **剔除受限设施内的工地**，并拿被剔除那几条的真实字段回扫兜底

所以下面这些**不会**出现在本仓库，也不该被手工加回来：受限设施内的项目、司机姓名／电话／准证、费率与合同额。
工地名和总包是可以的——公司业绩表里本来就公开着。

> 单文件。地图用 Leaflet + OpenStreetMap，需要联网。
